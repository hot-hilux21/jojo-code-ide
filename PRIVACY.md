# Privacy policy

**Windows app.** Code, settings and files stay on your computer. The only automatic network request is the optional update check, which can be turned off in Settings.

**Browser app** at https://jojocode.duckdns.org. Code is sent to the server to run and the output is sent back; the code is not kept after the run. The site has email-based accounts. If you sign in, the files, settings, code snapshot and avatar you save are stored on that server against your account. Settings saved in the app also go to the site's access-code-protected config store. Settings can be exported and imported as a JSON file. Accounts are optional; the editor works without signing in.

**Counters.** The hosted copy records a few usage counters for the maintainer in a local file on that server. No third-party analytics, advertising trackers or data sales.

**Signing.** Windows builds are unsigned. Signing is deferred because no free issuer is available yet; `docs/code-signing.md` records the intended route. Until a signed build is published, Windows may show a SmartScreen prompt.
