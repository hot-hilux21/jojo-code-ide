Frequently Asked Questions

How do I save my code?

Use the Save button in the editor strip, or press Ctrl+S. If you are logged in with a username account, turn on Autosave to push code to the server automatically.

How do I undo or redo?

Use the Undo and Redo buttons in the editor strip, or Ctrl+Z / Ctrl+Y.

How do I log in?

Click the login button (top right). You can sign in with Google or GitHub, or create a username and password account.

How do I change the font or theme?

Open Settings (top right) and pick a font, theme, and colours. Changes save as you make them.

How does text-to-speech work?

Turn on "Read results aloud" in Settings. The app reads output and errors after you run code.

Is my code private?

Yes. Code and settings stay on your device. Cloud sync is optional and uses your own Google Drive.
