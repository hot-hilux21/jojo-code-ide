Frequently Asked Questions

How do I save my code?

Use the Save button in the toolbar, or press Ctrl+S. If you are logged in with a username account, turn on Autosave to push code to the server automatically.

How do I undo or redo?

Use the Undo and Redo buttons in the editor strip, or Ctrl+Z and Ctrl+Y.

How do I log in?

Click the login button (top right) and create a username and password account, or sign in with the one you already have.

How do I keep my files and settings?

Once you are logged in, the Account box lets you save the code in the editor as a named file on the server, open a saved file again, and save or load your settings. Everything is held against your account.

How do I change the font or theme?

Open Settings (top right) and pick a font, theme and colours. Changes save as you make them.

How does text-to-speech work?

Turn on "Read results aloud" in Settings. The app reads output and errors after you run code.

Is my code private?

Yes. Code and settings stay on your device. If you create an account, the files and settings you save are stored on the server against that account.
