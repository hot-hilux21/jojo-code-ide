Privacy Policy

Jojo Code is offline-first. Your code and settings are stored locally on your device.

If you create an account, the files and settings you save are stored on the server against that account, and are removed when the account is.

Passwords are hashed before they are stored. We never send your password back, and we do not sell data.

Feedback you submit is stored locally on the server and may include the message you send.
